            ACT V · AUTHENTICITY & FAIL-CLOSED GENERATIVE BOUNDARY
          

          

            纪实真实性契约 · 生成式编辑的严苛授权边界
          

          

            摄影的力量源于真实。澄影在底层将「纯光学/周围像素传播算法」与「生成式 AI
            图层」彻底隔离：Agent 绝无权限自行开启生成式重绘，未获人类显式授权一律默认拒绝（Fail-Closed）。
          

        


        

          

            

              
              
              
            


            

              
              纪实摄影真实性完整 · NON-GENERATIVE

              
              

                ChengyingError: authorization-required (Fail-Closed v0.8.0)
                生成式图层已被核心服务拦截
                

                  普通 edit_apply 被模块私有 Symbol 锁死，无法创建或伪造 ai:gen_layer。必须在右侧点击模拟人类审批「允许一次」后方可写入可回退的生成遮罩层。
                

              

            


            

          


          

            

              
              
            


            

              

                
1. 私有 Symbol 锁死通用通道

                

                  EditService.applyOps 由私有
                  Symbol('authorized-generative-flow') 守护，任何子 Agent
                  试图手搓 JSON 注入或跨任务复制 gen_* 图层均直接拒绝。
                

              

              

                
2. 任务绑定原子收据与 SHA-256 验真

                

                  生成结果仅运行一次并存为 16-bit PNG 遮罩资产，绑定
                  taskId / authorizationId / assetSha256；每次渲染与导出均复核磁盘哈希，确保预览与终混像素 100% 确定一致。
                

              

              

                
3. IPTC 国际标准溯源与可逆回退

                

                  含生成图层的导出自动写入
                  compositeWithTrainedAlgorithmicMedia；一旦
                  edit_revert 撤销该图层，导出即恢复无生成标记的纯净纪实状态。
