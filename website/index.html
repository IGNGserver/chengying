            第四幕 · 成组统一修图
          

          

            一整组照片色调统一，也懂得何时不修就是最好。
          

          

            就像请来一位细心的老修图师：同一场景先认真修好一张代表作，再把温暖统一的色调顺手延续到同组照片；一旦发现提亮导致灯笼发白过曝，立刻退回改成局部提亮；碰到窗光本来就恰到好处的原片，干脆克制不动，原汁原味交付。
          

        


        

          
            安全安心：修图过程只读取照片与色调参数，绝不擅自乱动电脑里的其他文件夹。
          
          
        


        

          

          

        

      


      
      

        

          

            第五幕 · 修图与生成的清晰边界
          

          

            日常修图与 AI 生成分得清清楚楚，未经你点头绝不改画面。
          

          

            调亮光影、顺手擦掉天空里碍眼的电线或杂物，都是基于现场真实像素的日常修复，用起来顺手无阻；但只要涉及“无中生有”用 AI 重绘天空或改变画面内容，澄影一定会先停下来等你确认，并在导出照片信息里诚实注明。
          

        


        

          

            

              
              
              
            


            

              
              100% 现场实拍光影 · 无 AI 生成内容

              
              

                安全确认 · 等待你的决定
                正在准备用 AI 重绘天空，是否允许？
                

                  日常调色和去除电线不会触发这条确认；但更换天空会加入原本没拍到的 AI 画面，只有在你点击右侧按钮确认后才会执行。
                

              

            


            

          


          

            

              
              
            


            

              

                
1. 真实修补与 AI 生成严格分开

                

                  压高光、提暗部、去掉电线或镜头灰点都只基于现场拍到的真实画面；AI 换天等创作功能默认锁住，绝不悄悄偷换你的记忆。
                

              

              

                
2. 改得不好随时一键回到原片

                

                  AI 生成的画面会保存在单独图层中，原片文件始终只读保护；只要想反悔，随时一键撤回。
                

              

              

                
3. 导出自带“身份证”，真实含不含 AI 一目了然

                

                  纯实拍精修和包含 AI 生成的照片在写入文件信息时会清清楚楚区分，方便参加影赛或日常留档溯源。
                

              

            


            

          

        

      


      
      

        

          

            第六幕 · 支持的设备与三步上手
          

          

            相机 RAW 与手机照片开箱即修，三步开启你的数字暗房。
          

          

            无论是平时随手拍的手机 JPG / HEIC / ProRAW，还是索尼、佳能、尼康、富士、徕卡、哈苏等相机的 RAW 原片，装好就能直接选片和调色；若你电脑上已有 Darktable 或 RawTherapee，澄影也能自动联动它们并导出可继续微调的工程文件。
          

        


        

        


        

          自带 5 份摄影师审美修养，懂构图更懂克制

怎么开始用？三步就好


          

            

              第 1 步 · 安装澄影插件
              

                在 DeepSeek Harness 里添加澄影插件包，内置暗房引擎开箱即用，无需折腾复杂环境。
              

            

            

              第 2 步 · 选择摄影模式
              

                新建对话时挑选「澄影 · 摄影后期」预设，即可解锁全部智能选片与温和调色能力。
              

            

            

              第 3 步 · 像聊天一样吩咐修图
              

                发给它照片目录或选几张样片，直接用大白话告诉它想要的感觉，满意后再整组导出。
              

            

          


          

            

              不知道怎么开口？试试这样对它说：
            

            

              

                “帮我从刚导入的 200 张旅行照片里，挑出 15 张表情自然、对焦清晰的精选。”
              

              

                “这组夜景人像保留灯笼原本的暖光，把人脸稍微提亮，肤色自然一点别太假。”
              

              

                “按清透胶片的感觉统一修这一整组；原本光线已经很好的照片就保留原片别乱改。”
              

            

          


          
          

            
              
                展开安装命令与命令行工具（进阶用户 / 开发者）
              
            
            

              

                

                  

                    1. 添加到 DeepSeek Harness 工作台
                    
                  

                  
# 环境要求：Node.js >= 24.9.0，DSH >= 0.2.1-0 < 0.3.0
# darktable / RawTherapee 为可选搭配（未安装时内置暗房开箱可用）
pnpm install && pnpm build && pnpm pack
dsh plugin --profile web add ./chengying-0.8.0.tgz

# 新建对话时选择预设：「澄影 · 摄影后期」

                


                

                  

                    2. 可选命令行工具快捷指令
                    
                  

                  
# 检测本机暗房与可选引擎状态
chengying engines doctor

# 命令行直接对照片目录执行筛图与自然语言选片
chengying cull /Volumes/Photos/2026-expedition
chengying select /Volumes/Photos/2026-expedition "按行程叙事选 30 张代表作"
